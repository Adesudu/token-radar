How the number is made (model signal-1): implied value = TVL × category multiple × growth multiplier × maturity multiplier × breadth multiplier × size taper. The category multiple is what the market pays for that kind of protocol's TVL; growth is the 7-day TVL change clamped to −40%…+100%; maturity grows with how long the protocol has run with no token; breadth rewards each extra chain; the taper trims the largest books. No protocol name is special-cased — the same arithmetic scores every row.
